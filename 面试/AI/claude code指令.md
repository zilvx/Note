Claude Code 提供了一系列以 `/` 开头的"斜杠命令"，让你在交互会话中能快速控制它的行为。这些命令覆盖了从项目初始化到代码审查的完整工作流。

我把它们按使用场景分了类，方便你快速查找：

### 📋 命令速查表

| 分类        | 命令                   | 作用                                                                                                                                                                                                                                         | 最常用场景                                  |
| --------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------- |
| **项目设置**  | `/init`              | 扫描项目，生成 `CLAUDE.md` 记忆文件，让Claude理解你的项目[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://developer.aliyun.com/article/1724549#1)[](https://support.claude.com/en/articles/14552382-your-first-day-in-claude-code#1)。 | **首次使用**，或项目结构有大变动时。                   |
|           | `/memory`            | 直接编辑项目、个人或全局的 `CLAUDE.md` 记忆文件[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://mintlify.wiki/VineeTagarwaL-code/claude-code/reference/commands/slash-commands)。                                                    | 随时更新编码规范、项目架构等关键信息。                    |
| **对话管理**  | `/clear`             | **清空**所有对话历史，开始一个全新的任务[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://developer.aliyun.com/article/1724549#1)。                                                                                                    | 切换到完全不相关的任务时。                          |
|           | `/compact`           | **压缩**当前对话的上下文，生成摘要来释放Token空间，但保留关键信息[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://cloud.tencent.com.cn/developer/article/2673259?policyId=1004)[](https://developer.aliyun.com/article/1724549#1)。             | 对话冗长、感觉Claude响应变慢或快超出上下文窗口时（**非常实用**）。 |
|           | `/context`           | 以可视化方式展示当前上下文的占用情况[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://code.claude.com/docs/en/commands?utm_source=thenextgentechinsider.com&utm_medium=referral&utm_campaign=pulse_article#1)。                        | 想了解Token都用在哪了，排查上下文是否过载。               |
|           | `/rewind`            | **回退**代码更改和/或对话历史到之前的状态[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://cloud.tencent.com.cn/developer/article/2673259?policyId=1004)[](https://developer.aliyun.com/article/1718322#1)。                           | Claude改错了代码想撤销，按两下 `Esc` 键即可快速调出。      |
|           | `/btw`               | 在不打断主任务的情况下，插入一个**附带问题**[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://cloud.tencent.com.cn/developer/article/2673259?policyId=1004)[](https://developer.aliyun.com/article/1718322#1)。                          | Claude正执行耗时任务，你突然想查点东西。                |
|           | `/resume`            | 恢复或继续之前的某个对话会话[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://developer.aliyun.com/article/1718322#1)。                                                                                                            | 第二天想继续昨天未完成的工作。                        |
| **执行与模式** | `/plan`              | 切换到**计划模式**，Claude会先提供方案，待你批准后才执行[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://cloud.tencent.com.cn/developer/article/2673259?policyId=1004)[](https://developer.aliyun.com/article/1718322#1)。                 | 执行高风险操作（如数据库迁移、大规模重构）前**强烈建议使用**。      |
|           | `/model`             | 切换当前会话使用的Claude模型（如 Opus、Sonnet）[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://cloud.tencent.com.cn/developer/article/2673259?policyId=1004)[](https://www.aitop100.cn/infomation/details/33115.html#1)。         | 复杂任务想用更强模型，或简单任务想用更快模型时。               |
|           | `/effort`            | 调整模型在推理时投入的"思考"深度[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://cloud.tencent.com.cn/developer/article/2673259?policyId=1004)。                                                                                   | 简单修改变量名用低深度，设计系统架构时拉满。                 |
|           | `/batch`             | 将大规模更改任务分解，并在独立的git worktree中并行执行[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://cloud.tencent.com.cn/developer/article/2673259?policyId=1004)。                                                                   | 需要一次性修改几十个文件时。                         |
| **代码与审查** | `/diff`              | 显示自上次审查以来所有未提交的更改[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://developer.aliyun.com/article/1718322#1)。                                                                                                         | **提交代码前**，最后看一眼Claude都改了些什么。           |
|           | `/code-review`       | 对当前更改进行代码审查，查找正确性问题和优化点[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://code.claude.com/docs/en/commands?utm_source=thenextgentechinsider.com&utm_medium=referral&utm_campaign=pulse_article#1)。                   | 让Claude自己检查一遍代码，还能加 `--fix` 让它自动修复。    |
|           | `/security-review`   | 专门对当前更改进行**安全检查**[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)。                                                                                                                                                           | 提交涉及认证、权限或敏感数据的代码前。                    |
|           | `/commit`            | 生成符合规范的commit message，并执行提交[](https://github.com/6551Team/claude-code-design-guide/blob/main/part1/02-quickstart.md#1)[](https://mintlify.wiki/VineeTagarwaL-code/claude-code/reference/commands/slash-commands)。                          | 懒人福音，让Claude帮你写提交信息。                   |
| **监控与管理** | `/cost` (或 `/usage`) | 查看当前会话的Token消耗和预估费用[](https://cloud.tencent.com.cn/developer/article/2673259?policyId=1004)[](https://github.com/6551Team/claude-code-design-guide/blob/main/part1/02-quickstart.md#1)。                                                    | 随时关心你的钱包。                              |
|           | `/tasks`             | 查看后台运行的子任务（如subagent）状态[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)。                                                                                                                                                     | 让Claude并行执行任务时，用来查看进度。                 |
|           | `/doctor`            | 诊断Claude Code的安装和配置问题，并尝试自动修复[](https://code.claude.com/docs/zh-CN/commands#all-commands#1)[](https://cloud.tencent.com.cn/developer/article/2673259?policyId=1004)。                                                                       | 遇到奇怪的报错或配置问题时，先跑一遍。                    |

> **提示**：在会话中输入 `/help` 可以随时看到当前版本所有可用命令的列表[](https://developer.aliyun.com/article/1724549#1)[](https://mintlify.wiki/VineeTagarwaL-code/claude-code/reference/commands/slash-commands)。你也可以在启动时用 `claude -p "你的任务"` 来进行一次性非交互式执行[](https://developer.aliyun.com/article/1705912#1)[](https://cloud.tencent.cn/developer/article/2687170?policyId=1004#1)。
