带内通信通道（iBMC ↔ 主机 OS）

BT / KCS 接口

  • IPMI 本地通道
  • OS 侧 /dev/ipmi0 访问
  • SSIF (SMBus 系统接口)

SOL 串口重定向

  • Serial Over LAN
  • 文本控制台远程转发
  • TCP 端口映射

KVM over IP

  • 远程键盘/视频/鼠标
  • HTML5 / Java 客户端
  • 端口 2198 / 2199

虚拟媒体

  • ISO/IMG 远程挂载
  • USB Mass Storage 模拟
  • 远程 OS 安装

NC-SI 边带网络

  • 与业务网卡共享物理口
  • VLAN 隔离管理/业务流量
  • 管理平面与业务平面分离

iBMA Agent

  • 主机侧代理软件
  • PCIe 通道上报 OS 信息
  • 黑匣子崩溃数据写入
